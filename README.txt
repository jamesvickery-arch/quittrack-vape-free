QUITTRACK VAPE-FREE — PWA PACKAGE

WHAT'S INCLUDED
- index.html: the app
- manifest.webmanifest: installable app metadata
- sw.js: offline cache
- icon files: app icons

IMPORTANT
This ZIP is the app source package, not an App Store app. To install it as a PWA on iPhone, it must first be hosted on an HTTPS website.

EASIEST DEPLOYMENT: GITHUB PAGES
1. On a computer, sign in to GitHub and create a new public repository named quittrack.
2. Upload every file in this folder to the repository's root (not the ZIP itself).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. Your address will look like https://YOUR-USERNAME.github.io/quittrack/
6. Open that address in Safari on your iPhone.
7. Tap Share (square with arrow) > Add to Home Screen > Add.

The app stores settings and progress locally in the browser on that device. Clearing Safari website data or changing devices may remove that local data. The quit timer is calculated from the saved quit date when the app is opened; the app does not currently send push notifications.

To update the app, upload the replacement files to the same repository.
